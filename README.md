## 📖 Project Overview

A responsive Netflix clone built with HTML, CSS, and JavaScript. This project was originally created as a personal gift for someone special, but has since evolved into a comprehensive learning project that demonstrates modern web development techniques including responsive design, CSS animations, and interactive elements.

## ✨ Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Interactive Elements**: 
  - Animated FAQ accordion sections
  - Hover effects on buttons and navigation
  - Email input with floating labels
- **Modern UI/UX**: 
  - Netflix-inspired design and layout
  - Smooth animations and transitions
  - Professional typography using Poppins font
- **Multi-language Support**: Language dropdown with English and Hindi options
- **Video Integration**: Background videos for enhanced visual appeal
- **Accessibility**: Proper semantic HTML and keyboard navigation support

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: 
  - Flexbox and Grid for layout
  - CSS animations and transitions
  - Media queries for responsive design
  - Custom properties (CSS variables)
- **JavaScript**: Interactive functionality
- **Font Awesome**: Icons
- **Google Fonts**: Poppins font family

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software installation required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/khalid200704/AdesdanElis
   cd netflix-clone
   ```

2. **Open the project**
   - Simply open `index.html` in your web browser
   - Or use a local development server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js (if you have live-server installed)
     npx live-server
     ```

3. **View the website**
   - Navigate to `http://localhost:8000` (if using a local server)
   - Or directly open `index.html` in your browser

## 📱 Responsive Design

The website is fully responsive and optimized for:
- **Desktop**: 1024px and above
- **Tablet**: 768px - 1023px
- **Mobile**: Below 768px

## 🎨 Design Principles

- **Mobile-first approach**: Designed for mobile devices first, then enhanced for larger screens
- **Consistent spacing**: Using consistent padding and margins throughout
- **Color scheme**: Netflix-inspired dark theme with red accent colors
- **Typography**: Clean, readable fonts with proper hierarchy

## 🔧 Customization

To customize this project:

1. **Colors**: Modify CSS custom properties in `style.css`
2. **Content**: Update text content in `index.html`
3. **Images**: Replace images in the `img/` folder
4. **Styling**: Modify CSS classes and selectors
